# The Human Brain: Inside Your Control Centre

An interactive lesson for Class 10 learners, with Dr. Kaya as guide.

**Play it:** https://vaibhavgit31.github.io/Human_Brain_AI_Lesson/

- Use Chrome or Edge on a desktop or laptop. The first visit downloads the whole lesson, so give it a minute.
- Click once on the page to switch the sound on.
- Dr. Kaya's live answers use Google's API through the hosted assistant service; no provider key is included in this page.
- The latest update includes nine different wall anatomy videos, animated teaching boards, calmer lighting,
  quiet background music and one youthful Kokoro Puck voice for all 234 recorded lines and live answers.
- Live speech is generated on your device with the same free voice. Its first visit downloads about 112 MB of voice
  files in addition to the lesson. Answers appear as text while speech prepares; speed depends on the device.

This repository holds only the built lesson (branch `gh-pages`).
